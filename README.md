# Morrowisp: Daily Logic Puzzles

Morrowisp is a free logic puzzle game for iPhone and iPad. Predict how weather actions change a garden, find missing actions, and reason through step-by-step reveals.

- [Official website and support](https://samvaio00.github.io/morrowisp-support/)
- [How to play](https://samvaio00.github.io/morrowisp-support/how-to-play.html)
- [Press kit, screenshots and gameplay video](https://samvaio00.github.io/morrowisp-support/press.html)
- [Download on the App Store](https://apps.apple.com/us/app/morrowisp-daily-logic-puzzles/id6823244847)
- [Privacy policy](https://samvaio00.github.io/morrowisp-support/privacy.html)

All six chapters and daily puzzles are free. Occasional ads appear between rounds in some modes; one optional purchase removes ads permanently.

This repository hosts the public website and support information.
